Volley Stats v1.5 — iPhone installation

This package is a static Progressive Web App. It contains the OCR engine, English model, spreadsheet exporter, blank-sheet template, and all app code locally. v1.5 keeps the calibrated tally reader, removes combination/lineup analysis, and reads a handwritten set number plus score such as “1 21-25” from the existing Set line.

  1. Upload the contents of this folder to any HTTPS static host. GitHub Pages works well.
  2. On the iPhone, open the hosted index.html address in Safari.
  3. Let the first launch finish. The service worker caches all files for offline use.
  4. Tap Safari’s Share button → Add to Home Screen.
  5. Launch the Home Screen app once while online, then test it in Airplane Mode.

Privacy: the hosted files are only application code. Photos, roster, and season statistics are stored locally in the browser database and are not uploaded by this app.

Use Setup → Export season archive periodically to make a backup containing the season data and original/processed sheet photos.
