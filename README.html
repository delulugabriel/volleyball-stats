Volley Stats v2.0

GitHub Pages flat package. Upload every file in this folder to the root of the existing repository.

Recognition changes

  • Empty-first tally detection: blue colour noise no longer becomes an automatic 1.
  • A cell must contain a stroke with real vertical extent before it is counted.
  • Supports ordinary straight tallies such as eight separate marks.
  • Also recognizes a diagonal fifth mark crossing a group of vertical tallies and adds exactly one.
  • Small isolated blue JPEG/paper noise is discarded before counting.
  • Header remains manual with recent-match autofill; printed roster OCR is only for team suggestion.

Always verify highlighted cells before saving while this detector is being calibrated against real sheets.
