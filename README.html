Volley Stats v1.8

GitHub Pages package. Upload every file in this folder to the root of the existing repository.

What changed

  • Automatic first-pass detection of the four main-table corners, with manual fallback.
  • OCR engine loading fixed. v1.5 referred to a missing local vendor folder.
  • Two-pass image preprocessing for printed roster text and handwriting-oriented header OCR.
  • Two-team setup with a separate roster for each team.
  • Automatic team selection by fuzzy-matching OCR readings from the left-hand player column against both saved rosters.
  • Saved sets and summaries are kept separate by team.

Important

Open v1.8 while online at least once. The service worker attempts to cache the OCR engine and English language model for later offline use. Handwriting recognition is best-effort; verify the header and all tally counts before saving.
