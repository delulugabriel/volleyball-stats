1. Align the sheet

Tap the four corners of the main stats table in this order: top-left, top-right, bottom-right, bottom-left. Dragging is not required.

2. Header

Header OCR will run after alignment. Write the score beside the set number on the paper, e.g. 1  21-25.

3. Verify tally counts

Orange cells are low-confidence estimates. Tap/type any number to correct it. Pass Avg and Hit % are calculated automatically.

Roster order

Put players in the same row order as your printed stat sheet. Names on the uploaded blank sheet are ignored.

Data & backup

Data and photos stay in this app's local storage. Export a season archive periodically so you are not relying on one phone.

Tally calibration

The app learns an approximate ink-per-tally value from corrected sheets.

Privacy

No analytics, accounts, or cloud database. OCR and tally analysis run on-device. The app can operate with airplane mode on after installation.
