Teams & rosters

Set up both teams. The app OCRs the names/numbers printed down the left side of each photographed sheet and selects the roster with the best fuzzy match.

Data & backup

Data and photos stay in this app's local storage. Export a season archive periodically so you are not relying on one phone.

Tally calibration

The app learns an approximate ink-per-tally value from corrected sheets.

App updates

Version 1.6. When you reopen the app while online, it checks GitHub Pages for a newer version and refreshes itself automatically. Your season data remains on this device.

Privacy

No analytics, accounts, or cloud database. OCR and tally analysis run on-device. The app can operate with airplane mode on after installation.
