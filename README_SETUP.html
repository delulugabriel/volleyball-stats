Volley Stats v3.0 — GitHub Pages app

This is the phone/PWA half of the new hybrid scanner.

Upload

Upload every file in this ZIP to the root of your existing GitHub Pages repository, replacing the old app files. Commit the changes.

Then

Deploy the separate Volley Stats v3.0 Cloudflare Worker. When Cloudflare gives you the Worker URL, open the app on the iPhone and go to Setup → AI scanner connection. Paste the Worker URL and your private APP_TOKEN, then tap Test connection.

Scanning

The app compresses the photo on the phone, sends it to your private Worker, and receives structured stat counts. You always get a verification table before the set can be saved.

What stays local

Rosters, verified set data, accumulated season statistics, and your scanner settings are stored in the browser on the phone. Export a backup periodically.
